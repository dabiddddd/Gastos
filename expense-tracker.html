Privacy Policy
Last updated: 2026-08-25
No data collection
Gastos is fully offline. All entries, categories, presets and settings are stored locally in SQLite on your device. There is no account, no backend, no analytics, no ads, and no trackers.
Backups
JSON/CSV export creates a file you choose to save or share. Import merges by ID and never uploads data anywhere.
Crash reporting
Disabled by default. If you configure Sentry, only anonymized crash reports are sent, with no financial data.
Permissions
File access only when you explicitly export or import a backup.
Contact
Via App Store Connect or github.com/dabiddddd/Gastos
Your data never leaves this phone except through a backup you export yourself.
